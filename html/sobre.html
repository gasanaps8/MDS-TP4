Sobre o projeto

Porque é que o Agile Quest existe e quem o construiu.

🎯 O objetivo

O Agile Quest é um guia interativo que mostra como aplicar gamificação em cada fase do Scrum. Em vez de ler a teoria de uma só vez, o utilizador percorre as seis etapas do ciclo, da Release Planning à Sprint Retrospective, e em cada uma descobre o que acontece, quem participa e que mecânicas de jogo podem tornar esse momento mais envolvente para a equipa.

A gamificação é usada de forma responsável e centrada na equipa: pontos, desafios e cartas servem para motivar a colaboração, nunca para criar competição individual.

🧭 Como funciona

🗺️ Mapa de etapas

Seis etapas do Scrum em sequência, cada uma com o seu conteúdo.

🃏 Atividades interativas

Simulações como o Scrum Poker para experimentar o processo.

✅ Mini-quizzes

Perguntas rápidas no fim de cada etapa para testar o que aprendeste.

👥 A equipa

Projeto desenvolvido no âmbito da unidade curricular de Metodologias de Desenvolvimento de Software (ISEC).
